# Şahinkaya Mobilya — yuvarlak profil logoları

Bu beş yeni profil logosu, mevcut `assets/mini-logo.png` işaretini temel alır. Turuncu şeklin siyah dış çizgisi korunup belirginleştirilmiştir. Her PNG 1080 × 1080 pikseldir; dairenin dışı saydamdır.

| Dosya | Tasarım yönü |
| --- | --- |
| `01-klasik-muhur.png` | Çift halkalı klasik mühür |
| `02-modern.png` | Büyük işaret ve modern yazı |
| `03-editorial.png` | İsmi öne çıkaran zarif düzen |
| `04-iki-ton.png` | Siyah alt yarım daireyle yüksek kontrast |
| `05-isim-bandi.png` | Dairenin içinde siyah isim bandı |

[Karşılaştırma](karsilastirma.png) ve [170 px profil önizlemesi](profil-onizleme.png) seçim için hazırlandı. Küçük profil boyutunda en rahat okunan seçenekler 02 ve 04'tür.

Görseller, `scripts/uret-yuvarlak-profil-logolari.ps1` ile yeniden üretilebilir.
